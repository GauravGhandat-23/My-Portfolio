## ✨ Portfolio Design Language

The portfolio features a **Jaguar-inspired luxury minimalist pure white UI/UX**:

- **Pure White Aesthetic:** Immaculate `#FFFFFF` and `#F8F8F7` backgrounds with `#111111` typography and `#E5E5E5` hairline dividers.
- **Transparent Navigation:** Fixed transparent header overlaying the hero with active section indicators and an editorial full-screen mobile menu.
- **Interactive Portrait Frame:** Architectural gallery frame with precision registration corners. Clicking anywhere on the portrait smoothly toggles between **Classic Black & White**, **Natural Spectrum Color**, and **Cinematic Noir**.
- **Smooth Motion System:** Lenis smooth scrolling engine paired with Framer Motion transitions.
